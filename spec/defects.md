# Defect register

All bugs and inconsistencies found while deriving the spec from source
(see [README.md § Version](README.md#version) for the exact commit). This
file is the **single triage list**; each module spec also lists its own
defects locally, with more context, under the same IDs.

Most defects are internal contradictions (the code's own structure or
interfaces imply one thing, the code does another). A few, marked **(vs
Design Proposal)**, are instead gaps against the project's original
intent as documented in the Design Proposal for Development of a
Taxonomic Assignment Pipeline (QCIF, 2024-11-29) — the code is internally consistent but diverges from
what was originally specified before this code-derived spec existed.

Found by reading code, not by running it, unless marked **confirmed by
test/run**. Items marked *to confirm* depend on external tool behaviour.

**Severity**
- **High** — wrong or missing scientific result, a feature that cannot
  work, or a silent loss of output.
- **Medium** — misleading report/config, a validation gap that lets bad
  input through, or a latent crash.
- **Low** — cosmetic, documentation drift, dead code.

**Origin:** `v1` = the problem already existed in the code at `edaacae`, the commit the first version of this spec was derived from (whether it was logged then or found later). A commit hash = the problem was introduced by that commit, one of the seven in `edaacae..3339050` ([README.md § Version](README.md#version)).

**Status:** `open` unless stated. When fixed, change status to
`fixed in <version/commit>` and keep the row.
